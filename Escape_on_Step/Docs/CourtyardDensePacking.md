# Courtyardの密集配置

対象：`LVL_BackAlley_AutoCreateMap` / `BP_Courtyard_Generator`。

## 変更点

`Settings.bDensePacking`（Dense Packing）を有効にすると、道幅とCellSizeを保ったまま、曲がり角同士の間隔を縮める。従来の幅2セルの道では、曲がり道の内側に4セル幅以上の空白が残っていた。密集配置ではこの幅を2セルにする。

密集時は小さなL字・U字を組み合わせる。中央に折り返しの余白を要求する4区画テンプレートは3区画までにする。各区画の短いトンネルによる接続、周回路・分岐の保証、出口のない長い腕の短縮は維持する。

部屋を張り出しより先に作り、小さい配置枠の中でも歪な部屋のための場所を確保する。張り出しは向かいの道まで空白を埋めないようにし、曲がって戻る道を残す。

道幅、セルの大きさ、元の建物モデル、床・壁のマテリアルは変更しない。生成速度の改善や描画方式の変更は今回の対象に含めない。

## 調整

BPまたはマップ上のジェネレーターの `Settings > Dense Packing` が密集配置の切替。無効にすると従来の道の寸法と2～4区画のテンプレートを使う。

密集配置中の曲がり角間隔は `StreetWidth + 2` セル。`MinStreetLength / MaxStreetLength` と4区画指定は従来配置用として残している。`StreetCount`、`ExtraConnectionChance`、短いトンネルの長さ、部屋の個数・確率は引き続き使用する。

## 検証

生成の検証では道幅2・3、接続追加確率0・0.5・1、区画数9～24などを組み合わせる。接続・周回・分岐・不正データの拒否に加え、従来配置との実際の床の外接面積と密度を比較する。

変更前はプロジェクト内 `Saved/CodexBackups/20261116_CourtyardDense/Before` に保存。
