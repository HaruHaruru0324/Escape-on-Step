# Courtyard：密度と形の変化

対象は `LVL_BackAlley_AutoCreateMap` と `BP_Courtyard_Generator`。

## 生成の順序

1. 直角に曲がる2～4区画から道の骨格を作る。
2. 短い直線トンネルで全体を接続し、周回路と分岐を確保する。
3. 出口のない長い腕を短い出っ張りまで戻す。
4. 道の側面に奥行き1セル、長さ2～3セルの浅い張り出しを追加する。
5. 曲がり角の一部を、幅4セル・14～15セルの角が欠けた部屋へ広げる。
6. 部屋の実際の床の輪郭に壁を立て、外の道に接する境界に扉を設ける。
7. 全床の接続と、プレイヤーの大きさで実際に通れることを検証する。

## 今回の設定

- CellSize：400 → 320 cm。
- StreetCount：12。分岐・周回を減らす目的では変更しない。
- MinStreetLength / MaxStreetLength：4 / 6。骨格の成立に必要な最小長は別途確保する。
- MinTunnelCells / MaxTunnelCells：1 / 1。トンネル内は曲げない。
- 屋外の基本幅は2セル。部屋は最大4セル幅で、完全な4×4の空間にはしない。

## BPで扱うデータ

- Node.Sections：曲がった道の骨格。
- Node.DetailCells：短い張り出し・部屋の拡幅で追加した床。
- Node.FloorCells：上記を合わせた実際の床。
- RoomArea.Min / Size：部屋の外接矩形。
- RoomArea.FloorCells：部屋の実際の形。矩形の全セルを部屋と解釈しない。
- RoomArea.DoorCells / DoorDirections：扉の位置と外向きの方向。

張り出しはタイルの内側だけに作り、別の道やトンネルに勝手に接続しない。追加床は骨格から2歩以内に制限する。すべての区画で接続2本以上、独立した周回路3本以上、分岐区画4個以上を検証する。

既存の `LVL_BackAlley`、元の建物レベル、マテリアルは編集対象に含めない。
